# Security Policy

## Supported version

Security fixes apply to the latest released version.

## Report a vulnerability

Use GitHub private vulnerability reporting in this repository. Include clear reproduction steps and the affected version.

Do not open a public issue for a suspected vulnerability. Do not include credentials, OAuth data, customer content, or private service details in a public report.

Use GitHub Issues only for normal support and documentation problems.

## Public package boundary

This repository contains manifests, skills, public images, validation scripts, and public documentation. It does not contain the hosted ReelsFarm MCP server implementation or any authentication material.
